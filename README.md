# Heart Disease Analysis Using Python

## 1. Project Overview

Heart disease is a major global health concern. This project explores a heart disease dataset using Python, Pandas, Matplotlib, and Seaborn.

The purpose of this project is to perform exploratory data analysis (EDA), understand the distribution of patient characteristics, examine relationships between health indicators and the target variable, and identify patterns within the dataset.

## 2. Objectives

- Understand the structure and quality of the dataset.
- Identify missing values and duplicate records.
- Analyze demographic and clinical variables.
- Visualize relationships between patient characteristics and the target variable.
- Summarize the key findings from exploratory analysis.

## 3. Tools and Technologies

- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Seaborn

## 4. Dataset

The dataset contains patient characteristics and a target variable indicating heart disease status, according to the dataset's coding.

**Note:** This is an exploratory analysis of dataset records, not a medical diagnostic tool. Observed associations do not establish causation.
